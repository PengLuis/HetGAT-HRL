# HetGAT-HRL

Rebuild workspace for a multi-agent heterogeneous truck-UAV emergency logistics system.

## Top-level layout

- `code_and_models/`: all source code, configs, scripts, and model definitions.
- `training_results/`: all training logs, checkpoints, TensorBoard outputs.
- `artifacts/`: exported figures, replay media, paper assets.
- `docs/`: design docs and experiment protocols.

## Current status

Step 1 (MDP/SMDP formalization) is implemented as a clean interface-first baseline.
